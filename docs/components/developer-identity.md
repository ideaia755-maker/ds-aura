# Developer Identity — AI STUDIO ShenData

Подтверждённые сведения: студия и правообладатель **AI STUDIO ShenData**, разработчик **Константин Шендрик**. Источник — утверждённые блоки шапки, подвала и «О программе» приложения «Задания на производство» (index.html, client/ProductionAddon.cs), предоставленного владельцем 23.10.2026.

В src/branding/assets/ находятся побайтовые копии shendrik-logo-color.png и shendrik-logo-mono.jpg. Оригинальный знак Shendrik используется исходным приложением в блоке студии; отдельного знака студии нет. Не создавать новый знак и не перекрашивать оригиналы. Название студии выводится текстом рядом с логотипом. Метаданные — src/branding/identity.json.

```tsx
import { DeveloperIdentity, DeveloperFooter } from "aura-ui";
import "aura-ui/styles/globals.css";

<DeveloperIdentity productName="Название продукта" version="1.0.0" releaseYear={2026} />
<DeveloperFooter releaseYear={2026} />
```

DeveloperIdentity содержит доступную кнопку DeveloperBadge и управляемый нативный модальный dialog DeveloperAbout. В отдельном меню можно использовать DeveloperAbout напрямую с open/onOpenChange. Версия и название обязательны. Escape закрывает окно; браузер удерживает фокус в диалоге и возвращает его инициатору. Оригинал логотипа подключается локально через Vite, без внешнего сервиса. Для компактной шапки используется только цветной знак; монохромный вариант доступен для документов и печати.

Применяются существующие AURASurface, Button, токены глубины, стекла, типографики, состояний и темы: Obsidian Glass и Milk Glass. Фирменные цвета исходного логотипа сохраняются независимо от темы. Компонент поддерживает клавиатуру, reduced motion и узкие экраны.

Лицензия не имеет значения по умолчанию. Не переносить из производственного проекта Enterprise для ТПК «Мраморикс», рабочие места, данные администратора, поля ввода ключей или ограничения перепродажи. licenseText передаётся только из утверждённых условий текущего продукта. Сайт, контакты и юридические реквизиты не указаны, поскольку не подтверждены.

Для повторного использования агентами: skills/razrabotchik/SKILL.md содержит самостоятельный пакет исходников и инструкции. Он не разрешает публикацию или изменение лицензий других продуктов.
